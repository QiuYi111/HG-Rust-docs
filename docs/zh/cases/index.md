# 四个实操案例

如果你第一次接触 HG，先从这里开始。

这四个案例都来自实际运行过的工作流。它们分别做出一份学习手册、一期播客制作包、一套工程治理证据和一份 CAD 发布包。四个项目看起来差别很大，做法却有一条共同主线。

人先说清楚要交付什么。输入材料进入流程后，HG 按依赖关系安排工作。每一步都会留下可以检查的结果。材料发生变化时，只有受影响的部分重做。中途失败、取消或需要人决定时，流程可以从已经完成的地方继续。

| [CAD Release](cad-release.md) | 一组 PCB、模型、图纸、仿真、渲染和发布记录 | 想学习“多种工具串联、有限范围检查和人工放行” |

## 教程会怎么带你走

每个页面都从一个真实的工作目标开始。你先写出想要的结果，接着会遇到输入变化、人工确认、外部工具失败或多人同时工作的实际问题。教程就在这些问题出现的地方引出 HG 的做法，并让你立刻运行一次验证。

## 推荐学习顺序

1. 先读 [Learning Helper](learning-helper.md)，看懂“输入、处理、检查、交付”这条主线。
2. 再读 [Acquired Podcast](acquired-podcast.md)，看并行研究和受限网络如何加入流程。
3. 接着读 [Harness Lifecycle](harness-lifecycle.md)，看人工决定、权限和 Agent 如何协作。
4. 最后读 [CAD Release](cad-release.md)，看多工具和发布门如何组合。

每个教程都给出配置片段、完整案例目录、运行命令、修改输入后的操作和验证结果。先把 [HG-Rust 仓库](https://github.com/QiuYi111/HG-Rust) 克隆到你选择的目录，再从仓库根目录执行命令；案例运行器会自行准备本次运行所需的工作目录。

页面中的 `scripts/test-real-world-cases.sh` 命令都从 HG-Rust 仓库根目录执行。

## 先准备环境

先确认本机有 Rust/Cargo、`jq`、`sqlite3`、Python 3 和 Git。第一次阅读时先运行每个案例的 contract（本地可重复验证模式）；需要真实外部工具时，再按教程说明运行 live（真实工具模式）。案例运行器会自动提交固定的示范响应来验证门控和恢复，这不等同于真人审批。

教程采用“阅读配置片段，再运行验证程序”的方式。片段帮助你理解依赖关系，完整可运行配置和输入文件都在 HG-Rust 仓库的案例目录中，不需要从空目录手工拼出整套系统。

## 读完四个教程以后

如果你只需要某个小能力，可以再看[功能参考与小例子](../examples/reference.md)。那里把原来的十几个简单示例按主题合并，适合查命令和配置写法，不适合作为第一次阅读的入口。
