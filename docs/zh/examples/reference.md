# 功能参考与小例子

这里集中放快速查阅材料。第一次使用 HG，请先读[四个实操案例](../cases/index.md)。

原来的十几个案例主题已经按问题合并到下面几组。每组先给一句用途，再说明适合查什么。

## 先做出一个结果

- **最小协调**  用一个输入文件生成一个结果文件。
- **缓存、失效与修复**  看输入不变时如何复用结果，文件被改坏时如何恢复。
- **失败与恢复**  看上游已经完成时，后面的工作如何继续。

## 需要人参与

- **人工审批与外部效果**  把审批和外部动作放进同一条可检查的流程。
- **评审与修订**  让草稿、意见和修订有明确关系。
- **反馈循环**  处理需要多轮修改才能稳定的工作。

## 把流程拆开并行运行

- **子图**  把一段工作交给一个边界清楚的子流程。
- **并发与租约**  多个执行者同时工作时，避免旧结果覆盖新结果。
- **动态子图**  让上游结果决定下一段流程的结构。

## 运行时间更长，限制更多

- **预算与取消**  设置尝试次数、时间和取消行为。
- **守护进程与观察**  在后台运行并持续查看事件。
- **受限的代理任务**  控制网络、秘密和输出脱敏。
- **审计与解释**  查看一次运行为什么得到当前结果。

## 领域例子

- **硬件设计**  把要求、接口和测试计划串起来。
- **科学实验**  记录数据、观察、报告和局限。

这些页面用于查语法和单个能力。四个综合教程展示了这些能力如何一起工作。
